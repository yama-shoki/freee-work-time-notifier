# freee 退勤通知 Chrome 拡張機能

**freee の勤務終了タイミングと休憩終了を、デスクトップ通知で見逃しにくくする Chrome 拡張です。**

「今日は何時に退勤だっけ」「休憩はいつ終わるんだっけ」を毎回確認するのが面倒だったので作りました。  
freee の勤怠データをもとに、勤務完了前・勤務完了時・休憩終了前後を通知します。通知の内容やタイミングは拡張ポップアップから変更できます。

## ✨ できること

- 🕘 **退勤前に 2 回通知**  
  時間は変更できます。たとえば「10分前」と「1分前」を自由に調整できます。
- 🎉 **勤務完了時に通知**  
  予定勤務時間に達した時点で通知します。
- ⏰ **超過勤務も通知**  
  オプションで、勤務完了後も一定間隔で通知できます。
- ☕ **休憩終了前と休憩終了時に通知**  
  休憩開始時に時間を選ぶと、自動で通知します。
- 📊 **複数回の休憩に対応**  
  昼休みや離席など、複数回の休憩時間を合算して計算します。
- 🔧 **勤務時間をカスタマイズ可能**  
  8時間以外の勤務時間にも対応しています。
- 🔔 **通知音の ON/OFF**  
  通知にあわせて音を鳴らせます。
- 👆 **通知クリックで freee に戻れる**
- 🚪 **ケース別に freee を自動表示**  
  勤務完了・休憩終了・超過勤務ごとに、freee を自動で開くか選べます。
- 📌 **重要な通知は残る**  
  勤務完了や休憩終了などの重要な通知は、反応するまで残ります。
- 🔄 **毎日自動リセット / データ復元**  
  前日の通知状態を引きずらず、同日内の再読み込みでは復元されます。
- 🏁 **退勤済みの検出**

## 🎯 こんな人におすすめ

- freee 勤怠管理を使っている
- 8 時間勤務の退勤タイミングを忘れがち
- 複数回の休憩を取る（離席・習い事の送迎など）
- Chrome ブラウザを使用している(Dia なども対応)

## 💻 使い方

### 基本の流れ

1. freee 勤怠ページを開く
2. **「修正」** ボタンを押す
3. その時点の勤怠データから、勤務完了予定時刻を再計算する
4. 設定したタイミングで通知が届く

> **重要**  
> 正確な勤務完了予定時刻に更新したいときは、freee 側で **「修正」** ボタンを押してください。  
> ページを開いただけでは、最新の勤怠状態とズレることがあります。

### 設定できること

拡張ポップアップから、次の設定を変更できます。

- **予定勤務時間**
- **1回目の通知タイミング**
- **2回目の通知タイミング**
- **超過勤務通知の ON/OFF と間隔**
- **通知音の ON/OFF**
- **勤務完了 / 休憩終了 / 超過勤務ごとの自動オープン**

### freee 自動オープン設定

次のケースごとに、freee のタブを自動で表示するか選べます。

- **勤務完了**
- **休憩終了**
- **超過勤務**

挙動は次のどちらかです。

- すでに freee のタブがある場合: そのタブを前面表示
- freee のタブがない場合: `https://p.secure.freee.co.jp/` を新規タブで開く

### ✅ ステータス表示

拡張機能のポップアップでは、いまの勤務状態を確認できます。

- **出勤前**：出勤ボタンが表示されている状態
- **勤務中**：現在の状況と完了予定時刻
- **退勤済み**：実際の勤務時間
- **超過勤務中**：超過時間の表示

> **注意**：ページ再読み込み後や再度 freee のページを開く場合は、計算がズレる場合があります。正確な時間と現在のステータスは「修正」ボタンで確認してください。

### 通知の種類

- **退勤前通知**  
  設定した 2 回のタイミングで届きます。
- **勤務完了通知**  
  予定勤務時間に達した時点で届きます。
- **超過勤務通知**  
  設定をオンにしている場合のみ、勤務完了後も一定間隔で届きます。
- **休憩終了前通知 / 休憩終了通知**  
  休憩開始時に選んだ時間をもとに届きます。

### 通知音

- **通知音を鳴らす** をオンにすると、退勤時刻や休憩終了時に音が鳴ります
- 通知の種類によって音を切り替えています
- 設定完了や休憩開始など、一部の確認通知では音は鳴りません

### 通知クリック

- 通知をクリックすると freee の勤怠ページに移動します
- 既に freee のタブが開いている場合は、そのタブをアクティブにします

## 🛠️ よくある質問

<details>
<summary><strong>Q. 通知が来ない</strong></summary>

- ブラウザと macOS の通知権限を確認してください
- freee のページで一度 **「修正」** ボタンをクリックしたか確認してください
- 拡張を更新した直後は、一度 freee ページを再読み込みしてください
</details>

<details>
<summary><strong>Q. 休憩を複数回取る場合は？</strong></summary>

- 自動で全ての休憩時間を合計して計算します
</details>

<details>
<summary><strong>Q. 残業している場合は？</strong></summary>

- 8 時間完了時点で一度通知します
- ポップアップから超過勤務通知を有効にしている場合は、さらに設定した間隔で定期的に通知が届きます
</details>

<details>
<summary><strong>Q. 翌日はどうする？</strong></summary>

- 日付が変わると、前日の設定は自動でリセットされます。再度、「修正」ボタンを押してください。
</details>

<details>
<summary><strong>Q. ブラウザを再読み込みしたら設定が消える？</strong></summary>

- データ復元機能により、同日内であれば再読み込み後も設定が復元されます
- ただし正確な時間確認には **「修正」** ボタンをクリックしてください
</details>

<details>
<summary><strong>Q. 退勤記録済みなのに勤務中と表示される？</strong></summary>

- 自動的に退勤済みを検出して表示を更新します
- おかしい場合は **「修正」** ボタンで最新状態に更新してください
</details>

<details>
<summary><strong>Q. 通知音が鳴らない</strong></summary>

- ポップアップの **「通知音を鳴らす」** にチェックが入っているか確認してください
- ブラウザやOSの音量がミュートになっていないか確認してください
</details>

<details>
<summary><strong>Q. 通知音を消したい</strong></summary>

- ポップアップの **「通知音を鳴らす」** のチェックを外してください
</details>

<details>
<summary><strong>Q. freee を自動で開く機能は何をするの？</strong></summary>

- 勤務完了・休憩終了・超過勤務ごとに、freee タブを自動表示するか選べます
- すでに freee タブがある場合は前面表示、ない場合は新規で開きます
- 退勤前の通常警告では自動オープンしません
</details>

## ⚠️ 注意事項

> **重要**: この拡張機能は freee 公式ではありません

> 正確な通知時間は freee 側の **「修正」** ボタンを押すと更新されます

> 日をまたぐ勤務や夜勤のようなケースには対応していません
